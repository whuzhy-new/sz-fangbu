# 深圳房补通勤地图

用户授权自主选择和调整方案，交付可用 WebApp；零额外付费，不购买企业 API、流量包或付费云资源。

当前阶段只在本地调试，不更新 Site；发布等待用户后续指示。界面只保留用户引导和必要说明，不使用宣传语，减少次级标签与重复描述。

- 操作区使用上下两张卡片，左侧对齐并留出间距。第一张放办公工区单选卡片、范围图层多选卡片，删除工区叠加选项，仅显示选中工区；第二张统一放地点搜索、搜索结果及路线分析，内容较长时在第二张卡片内滚动。不保留独立巨大 Header。成功状态统一为「符合房补条件」。
- 工区选择使用单行紧凑卡片，依次显示「深圳湾、景湖、太子」；地图标记及实际路线终点仍使用工区全称。
- 查询中的状态由接口实际进度驱动，依次显示「正在查询步行、自行车方案」「正在查询地铁不分段方案」「正在查询地铁分段方案」。跳过的阶段不显示，找到符合方案后显示「符合房补条件」。
- 地址仅在用户按 Enter 时发起搜索；方向键选中候选后，Enter 确认地点。输入、聚焦不自动查询；空结果提示只在提交搜索且返回空结果后显示，不再附加地图选点提示。
- “高德复核”打开弹窗；分段方案展示进站接驳、站间地铁、出站接驳三个二维码，地铁换乘合入同一站间二维码。提示用手机扫码，在高德查看路线并截图，网页版部分功能缺失。完整地铁方案保留一个完整路线二维码。二维码在本地生成，手机上也可点二维码打开高德。
- 方案与数据说明支持展开收起的高度和透明度过渡，搜索列表、查询状态及弹窗使用短暂淡入淡出；连续操作可反向衔接，收起内容不可聚焦，尊重系统减少动态效果设置。
- 方案列表依次缓入，地铁方案展开后标题使用浅色底，明细使用更淡的底色。步行、自行车方案仅展示摘要，不提供展开箭头或明细；点击仍可选中并展示地图路线。
- 超时方案的摘要文字、图标与时长置灰，保持可点击、可键盘操作；地铁仍可展开，步行和自行车仍可选中地图路线。
- 地图选点弹层按选中工区的三个原始范围图层即时预览判断及命中方式；图层开关只控制可见性，羽化不改变判断边界。内洞不算覆盖，边界计入；数据缺失显示不可用，不当作范围外。确认后与地址搜索使用同样的三阶段路线查询。
- 点击地图地点文字时，直接使用热点的地点名称，确认框、选定地点和后续路线起点名称一致；没有文字的空白处使用「地图选点」。小范围拖动入口保留地点名。
- 点击地图或拖动标记暂存候选地点并预览范围判断，确认框锚定在标记旁；点击「确认地点」后立即按坐标查询高德方案，大卡片只展示查询进度及路线结果，不展示范围估算。取消选点保留原有结果。搜索结果和已完成的工区核验结果保留，切回已完成工区无需重复查询。
- 地图选点只允许确认当前工区三个原始图层合集内，或距其最近边界不超过500米的地点；范围外超过500米禁用“确认地点”，显示“当前区域大概率不在房补范围内，暂不支持计算路线”。图层显隐不影响这个限制，孔洞同样按距覆盖区域的实际距离处理，确认回调再次检查；范围数据不可用时禁止确认。

- 三个工区：深圳湾创新科技中心、太子广场、景湖大厦。创新科技中心公司侧候选站必须包含粤海门，不能仅按最近站选择。
- 提前计算覆盖图，打开即可浏览；支持工区切换和三种方式图层。
- 地址核验按工区依次进行三个阶段：①步行直达≤30分钟、自行车直达≤20分钟，任一满足即结束，不查询地铁；②高德点位→工区完整地铁方案≤20分钟即结束；③前两阶段均未找到符合时限的方案，才查询分段地铁。叠加工区时各工区独立判断。
- 完整地铁方案采用接口总时长，再按分钟取整，仅允许步行与地铁，不含公交、打车等。某方式查询失败时保留错误与已有结果，继续尝试后续方式，不能将错误当作不符合。
- **2026-11-09 最新明确口径**：地铁组合只加「小区门口到进站口的步行/骑行 + 高德站间地铁路段时间 + 站内换乘时间 + 出站口到工区的步行/骑行」，只排除首次进站和最终出站的站内步行，计入站内换乘。使用高德地铁路段耗时字段，不能把完整方案总时长冒充纯运行时间，不能臆测扣减固定进出站时间。
- 页面须区分用户自定义分段口径与高德原始总时长；不能承诺该自定义口径必然获得公司审批。
- 地铁固定段必须用明确首末站 originpoi/destinationpoi 的高德站间 API；返回首末站须匹配，不能直接截取整段通勤方案中的地铁段，遗漏前往其他实际上车站的步行。
- 搜索小区/地址、修正小区门口、显示具体工区与符合方式、完整计算过程和分段高德复核入口。
- 地图范围允许校准模型，但需标注图源、误差、计算日期、分辨率；查询具体地址应使用高德核验。额度/网络失败必须显示未完成核验，不能假装不符合。
- 分段查询从实际坐标一次计算全部预备站口的本地步行、骑行接驳，比较所有组合；高德最多复核3个接驳、每站最多2个，500米内最近入口优先步行核验，同站相反方向的邻近入口也保留步行核验机会，其余按本地总时长排序，符合即停止。高德请求共用4.5秒等待预算，为5秒响应目标留出余量，超时取消排队与网络请求，保留本地比较及已返回的高德结果；本地估算不能确认符合或排除资格，不设置“继续查询”批次按钮。
- 用户要求面积≤1万平方米的内部小洞直接作显示补全，包含图层叠加形成的小洞；不拓展外边界，不改变地点核验的路线和时限。较大的内部空洞继续做高德及地物核验。
- 范围边界圆滑并扩大羽化（约40米高斯模糊尺度，4～12像素）。边界内外120米内，以及较大内部空洞边缘，选点提示“边缘地带，是否满足需核验”；其他通勤方式有稳定内部覆盖时仍按内部处理。只改变预览与图层显示，不改变原始覆盖数据或实际路线核验。
- 时长按分钟四舍五入（18分31秒→19分），取整后为0分的按1分计算。直达方案取整总时长，分段方案每段先取整、各段最少1分再相加；显示、资格判断、候选筛选与预计算范围均使用相同口径。保留API原始秒数供复核。
- 每月租住 16 个工作日仅提示，不由地图推断。

验收：生成真实覆盖数据，独立样本验证模型，真实地址和边界值测试；完成构建与浏览器交互 QA，交付可打开的应用。
