# 深圳房补通勤地图

用户授权自主选择和调整方案，交付可用 WebApp；零额外付费，不购买企业 API、流量包或付费云资源。

- 三个工区：深圳湾创新科技中心、太子广场、景湖大厦。创新科技中心公司侧候选站必须包含粤海门，不能仅按最近站选择。
- 提前计算覆盖图，打开即可浏览；支持工区切换、叠加和三种方式图层。
- 步行直达 30 分钟、自行车直达 20 分钟。
- **2026-11-09 最新明确口径**：地铁组合只加「小区门口到进站口的步行/骑行 + 地铁运行路段时间 + 站内换乘时间 + 出站口到工区的步行/骑行」，只排除首次进站和最终出站的站内步行，计入站内换乘。使用高德地铁路段耗时字段，不能把完整方案总时长冒充纯运行时间，不能臆测扣减固定进出站时间。
- 页面须区分用户自定义分段口径与高德原始总时长；不能承诺该自定义口径必然获得公司审批。
- 搜索小区/地址、修正小区门口、显示具体工区与符合方式、完整计算过程和分段高德复核入口。
- 地图范围允许校准模型，但需标注图源、误差、计算日期、分辨率；查询具体地址应使用高德核验。额度/网络失败必须显示未完成核验，不能假装不符合。
- 每月租住 16 个工作日仅提示，不由地图推断。

验收：生成真实覆盖数据，独立样本验证模型，真实地址和边界值测试；完成构建与浏览器交互 QA，交付可打开的应用。
